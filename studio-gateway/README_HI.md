# KHABAR DHUN Studio Gateway

यह component physical newsroom के local network में चलता है। Master Control सीधे cameras/lights/audio/encoder/LCD/Red Light को cloud से control करने का दावा नहीं करता; Gateway secure local bridge है।

Adapters को वास्तविक hardware/vendor APIs से configure करना आवश्यक है। `NOT_CONFIGURED` device को CONNECTED नहीं माना जाता।
