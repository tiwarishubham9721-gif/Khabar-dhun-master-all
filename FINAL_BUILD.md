# Final build map

## One permanent control plane
`Master Control -> Master AI Command Center -> Departments/Services/Anchors -> News/Verification -> Programming -> Output -> Platforms/Website/E-paper/Ads/Call Centre`

## External boundaries
Any item needing an account, credential, cloud runtime, third-party API, renderer, TTS, telephony or hardware stays `REQUIRED_NOT_CONNECTED` until an actual connection and health test succeeds.

## Master Output
The software stores the selected logical source (`DIGITAL_BACKUP`, `PHYSICAL_STUDIO`, `EMERGENCY_BACKUP`). This is **not** an actual video signal. A real encoder/output pipeline and dedicated output-only LCD are required.

## Master AI Command Center
Current safe commands can register a department, anchor or service, run system health, and trigger security lockdown (owner only). Arbitrary filesystem/code execution is deliberately disabled. Future AI provider integration can add richer commands without creating another panel.
